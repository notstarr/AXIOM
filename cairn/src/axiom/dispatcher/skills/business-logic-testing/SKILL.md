## 这是什么

一份业务漏洞测试的启发清单。遇到对应业务场景时翻一翻，确保不漏掉常见攻击面。不是限制——你发现清单外的东西当然也要测。

## 1. 支付与交易

| 检测项 | 具体场景 |
|--------|---------|
| 金额篡改 | 修改订单金额、商品单价、运费、税费 |
| 货币/汇率操纵 | 切换低价货币、汇率计算绕过 |
| 支付状态绕过 | 伪造支付成功回调、跳过支付步骤直接确认 |
| 负数金额 | 商品数量为负、退款金额大于实际支付 |
| 小数精度 | 利用四舍五入误差（如 0.001 显示为 0.00） |
| 重复支付/重复回调 | 同一订单多次回调导致多次发货/到账 |
| 支付通道篡改 | 低价支付通道回调用于高价订单 |
| 优惠券叠加计算 | 多种折扣（满减+券+会员折扣）叠加顺序导致负金额 |

## 2. 优惠与促销

| 检测项 | 具体场景 |
|--------|---------|
| 优惠券叠加 | 多张优惠券重复使用、与其他折扣叠加 |
| 优惠券绕过 | 删除优惠券校验参数、修改优惠券适用范围 |
| 优惠券跨用户 | 用别人的 coupon_no/instance_num 下单 |
| 优惠券面值篡改 | 修改券的 value/discount 参数使折扣变大 |
| 优惠券并发 | 同一张券并发用于多个订单是否都生效 |
| 满减绕过 | 修改凑单商品后立即退款，保留主商品优惠 |
| 新人/首单限制绕过 | 修改设备标识、注册时间判断绕过 |
| 限时/限量绕过 | 修改系统时间、库存判断逻辑绕过 |
| 领券绕过 | 突破每人限领数量、重复领取同一张券 |
| 活动规则绕过 | 拼团成功后退款但保留优惠、砍价后不购买但保留砍价记录 |

## 3. 秒杀与库存

| 检测项 | 具体场景 |
|--------|---------|
| 并发竞争 | 超卖、库存为负、重复扣减 |
| 限购绕过 | 修改用户标识、多次提交绕过每人限购、客户端限购参数篡改 |
| 秒杀提前进入 | 直接访问秒杀接口绕过时间校验 |
| 锁机制绕过 | 删除/修改锁参数导致库存异常 |
| 购物车篡改 | 修改购物车商品数量/价格、跨用户操作购物车 |
| 预售绕过 | 定金订单不付尾款但锁定库存、预售商品按普通价购买 |

## 4. 会员与权限

| 检测项 | 具体场景 |
|--------|---------|
| 会员特权绕过 | 未付费直接调用 VIP 接口 |
| 试用期绕过 | 修改设备标识、时间判断无限试用 |
| 内容解锁绕过 | 直接访问付费视频/文档 URL |
| 等级/积分伪造 | 修改等级参数、积分数值 |
| 垂直越权 | 普通用户 token 调用管理接口 |
| 会员状态自激活 | 篡改 membership_card_status 参数 |
| 会员到期续费绕过 | 到期后仍可享受特权、续费金额篡改 |

## 5. 虚拟资产与金融

| 检测项 | 具体场景 |
|--------|---------|
| 积分操纵 | 积分兑换比例篡改、负积分操作、0 积分兑换 |
| 提现绕过 | 绕过实名认证、绕过最低提现门槛 |
| 转账漏洞 | 转账给自己、转账金额篡改 |
| 充值漏洞 | 充值金额篡改、充值状态伪造 |
| 套利攻击 | A→B 货币兑换→B→A 汇率差套利 |
| 积分竞态 | 并发兑换导致积分超额扣减 |
| 负数转账 | 转账金额为负导致对方扣款自己到账 |
| 退款套利 | 退款后积分/优惠券未回收，退款金额大于实付 |

## 6. 注册与邀请

| 检测项 | 具体场景 |
|--------|---------|
| 批量注册 | 绕过手机号/邮箱唯一性校验 |
| 邀请码刷单 | 伪造邀请关系、自邀请套利 |
| 实名认证绕过 | 使用他人身份信息、假证件绕过 |
| 返利操纵 | 修改返利比例、层级绕过 |
| 注册奖励套利 | 注册→领奖励→注销→再注册循环 |

## 7. 账号与认证

| 检测项 | 具体场景 |
|--------|---------|
| OTP 暴力破解 | 验证码接口无频率限制，可遍历验证码空间 |
| OTP 绕过 | 不发送验证码直接调用验证接口 |
| OTP 重放 | 已使用的验证码再次使用 |
| 密码重置劫持 | 重置 token 可预测、重置接口越权 |
| 账号绑定劫持 | 换绑手机/邮箱无充分验证 |
| 会话固定 | 登录后 session 不更新 |
| 账号注销复活 | 注销后账号仍可登录、注销后手机号可重新注册并继承数据 |

## 8. 数据越权 (IDOR)

| 检测项 | 具体场景 |
|--------|---------|
| 水平越权-读取 | 枚举 ID 查看他人订单/地址/消息/文件 |
| 水平越权-修改 | 篡改他人地址/订单/资料 |
| 水平越权-删除 | 删除他人地址/订单/文件 |
| 垂直越权 | 普通用户调用管理接口 |
| 批量枚举 | ID 可预测 + 无归属校验 = 批量数据泄露 |
| 跨流程泄露 | A 流程泄露的 ID 用于 B 流程越权（如通知泄露 order_id） |
| 批量操作越权 | 批量接口（批量删除/查询）的 ID 列表包含他人 ID |
| 导出越权 | 导出功能未校验数据归属，导出他人数据 |

## 9. 状态机与流程绕过

| 检测项 | 具体场景 |
|--------|---------|
| 跳过步骤 | 跳过中间步骤直达终点（如跳过支付直接确认） |
| 回退状态 | 已完成订单回退到待支付、已签收回退到待发货 |
| 并发状态转换 | 并发请求导致状态不一致（同时支付+取消） |
| 状态参数篡改 | 客户端传入 status 参数直接修改订单状态 |
| 取消竞态 | 取消操作和依赖操作并发导致资源未正确释放 |
| 审批绕过 | 多级审批跳过中间审批人、自审批 |

## 10. 订单与履约

| 检测项 | 具体场景 |
|--------|---------|
| 订单篡改 | 下单后修改商品/数量/地址/价格 |
| 虚假签收 | 未收货确认签收、替他人签收 |
| 退款滥用 | 退款后不退货、部分退款后全额退货 |
| 订单关联绕过 | 拆单绕过限购、合并订单绕过优惠限制 |
| 发货地址篡改 | 下单后修改收货地址到他人地址 |
| 自动取消绕过 | 超时自动取消订单的优惠券/库存未正确释放 |

## 11. 消息与通知

| 检测项 | 具体场景 |
|--------|---------|
| 消息越权 | 读取他人消息/通知 |
| 消息伪造 | 伪造系统消息、伪造他人发送消息 |
| 推送滥用 | 向他人发送推送通知、短信轰炸 |
| 通知信息泄露 | 通知中包含完整 PII（手机号/身份证）、订单详情泄露给非订单人 |

## 12. 搜索与枚举

| 检测项 | 具体场景 |
|--------|---------|
| 数据枚举 | 搜索/列表接口无分页限制，可拉全量数据 |
| 用户枚举 | 通过搜索/接口枚举用户信息 |
| ID 枚举 | 连续/可预测 ID 批量获取数据 |
| 批量爬取 | 接口无频率限制可批量爬取商品/用户/订单数据 |
| 搜索注入 | 搜索参数注入导致返回非预期数据（如 SQL wildcard、NoSQL 注入） |

## 13. 投票与互动

| 检测项 | 具体场景 |
|--------|---------|
| 刷票 | 突破每人限投次数、并发重复投票 |
| 投票篡改 | 修改票数参数、修改投票选项 |
| 点赞/收藏操纵 | 并发点赞导致计数异常、取消后计数未减 |
| 评论操纵 | 评论后删除但评论计数未减、批量评论刷屏 |
| 排行榜操纵 | 通过刷量操纵排行榜、刷量影响推荐算法 |

## 14. 预订与预约

| 检测项 | 具体场景 |
|--------|---------|
| 超量预订 | 并发预订导致超额、库存为负 |
| 预订抢占 | 预订后不确认但占用名额、抢占他人预订 |
| 时间篡改 | 修改预约时间到已过期/未开放时段 |
| 取消滥用 | 取消预订但资源未释放、取消后立即重新预订绕过冷却 |
| 预约越权 | 查看/取消他人预约 |

## 15. 加密与数据保护

| 检测项 | 具体场景 |
|--------|---------|
| 密钥恢复 | 已知明文+密文对恢复 AES 密钥 |
| ECB 块替换 | 相同明文产生相同密文，可替换块修改明文 |
| 固定 IV 利用 | CBC 固定 IV + 已知明文 = 密钥恢复 |
| PII 脱敏不一致 | 列表接口脱敏但详情接口返回完整 PII |
| 响应完整性 | 响应签名/MAC 是否为静态常量（可篡改响应） |
| 加密可逆 | 客户端传入加密参数，服务端解密后使用但未校验完整性 |
