## 上下文读取规则

开始探测前先读取上下文清单，然后完整读取其中的 `hints.json`、`knowledge.json` 和 `vulnerabilities.json`。任务提示（Hint）是本任务的强制约束，项目知识（Knowledge）是需要遵循的业务背景，已有漏洞及其状态原因用于避免重复测试和重复上报。之后查看本轮相关技能，再按需读取其它索引和详情文件；不要默认展开全部历史产物（Artifact）或证据（Evidence）。

## 技能使用规则

`whatisvul` 是本阶段的强制前置技能，不是“可能需要时再读”的可选项。读取高价值上下文后、开始任何网络探测或编写产物前，必须先运行 `axiom skill path whatisvul`，并完整读取返回目录中的 `SKILL.md`。读取失败时先运行 `axiom skill doctor whatisvul` 排障并重试，不得凭记忆或常识替代。即使引导阶段不负责逐条上报漏洞，也必须用该技能的标准区分 `findings.md` 中的已确认漏洞与 `initial_leads.md` 中的待验证线索。

在开始以及执行下一步操作前，先查看当前会话自己的技能目录；只读取本轮操作需要的 `SKILL.md`，不要复制或一次性加载全部技能。脚本型技能使用 `axiom skill path <name>` 获取绝对目录；命令不可用时运行 `axiom skill doctor <name>` 定位原因，不要猜路径或执行全盘 `find`。技能要求与任务边界冲突时，以任务边界和系统规则为准。
