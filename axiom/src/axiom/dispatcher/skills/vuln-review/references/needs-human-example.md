# `needs-human` 裁决理由示例（不产出报告）

> 除「确认成立」外，其余裁决**不产出报告**，只在裁决 `--reason` 里说明（1-3 句，精炼直击要害）。

**场景**：验证需要第二个租户的真实凭证，当前 Lease 无法取得，且无法安全地用其他方式证明归属校验缺失。

**裁决命令**：

```bash
axiom review decision submit needs-human --reason "需要第二个租户的可用凭证才能构造单变量对照；已尝试自注册与复用同域 Cookie，均不可行。"
```

**要点**：必须写清**具体阻塞**与**已尝试的步骤**，而不是含糊地写"建议人工确认"。
