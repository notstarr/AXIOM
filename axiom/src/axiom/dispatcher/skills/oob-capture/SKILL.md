# 带外回连捕获（OOB）使用说明

有些漏洞不会把结果回显给你：你发了请求，响应永远 200/500，但服务端可能已经去访问了你给的地址。**带外捕获就是给这类盲打留一个只有你能看的落点**。

## 1. 先查，再开

**规则：永远先 `status`。已经开着就直接用，不要重新 `start`。**

```bash
axiom oob status          # 运行中？URL？还剩多久？
```

- `running: true` → **直接拿这个 URL 用**，不要 `start`
- `running: false` → 再 `start`

`start` 本身是幂等的：已经开着的再 `start` 只会**延长 10 分钟并返回同一个 URL**，不会换 token。所以「URL 已经写进目标了」这件事不会被你自己搞坏。但**能不调就不调**——顺手延长会掩盖「其实早该过期」的事实。

## 2. 拿 URL

```bash
axiom oob start                    # 打印 URL / 剩余 / 命中
axiom oob start --quiet            # 只输出 URL，方便 shell 取用
URL=$(axiom oob start --quiet)
```

输出形如：

```
https://124.220.165.118:8888/oob/483920
```

**一个 AXIOM 只有一个桶，所有 worker 共用。** 不按任务隔离，因为不需要——回连本身带着来源 IP、User-Agent、时间和路径标签，足以判断是谁打回来的。

## 3. 在 URL 后面加标签

```
https://124.220.165.118:8888/oob/483920/i052-ssrf
https://124.220.165.118:8888/oob/483920/i103-xxe
```

**强烈建议每次都加 `<意图ID>-<用途>`**。共用 token 时，标签是唯一能把回连归属到「哪条意图打的」的信息；不加标签，五个 payload 的回调会混成一片，事后只能靠时间戳猜。

标签会原样进 `list` 输出，也会出现在血缘视图里对应意图的成果卡上。

## 4. 查回连

```bash
axiom oob list                          # 最近 50 条
axiom oob list --label i052             # 只看某条意图
axiom oob list --json                   # 原始 JSON，给脚本用
```

每条记录包含：时间、**次数**、来源 IP、方法、标签、路径、query、User-Agent、Host、Referer、body 大小与前 2KB 预览。

相同的 `(来源IP, 标签, 方法, query, body前200字节)` 会**合并成一条并累加次数**——目标在重试循环里打一万次，列表也不会被淹。

## 5. 关掉

```bash
axiom oob stop             # 立即关闭 + 清空全部记录
```

**十分钟到了会自动关闭并清空**，不需要手动 stop。进程重启也等于清空。

## 6. 什么时候该用 / 不该用

| 值不值得用 | 场景 |
|---|---|
| ✅ **该用** | 盲 SSRF（服务端取 URL）、盲 RCE（`curl`/`wget`/`ping` 回连）、XXE 外部实体、无回显的命令注入、反序列化回连 |
| ⚠️ **能但要快** | 盲 XSS、存储型回调——10 分钟窗口可能等不到人点，**窗口内没命中不等于没漏洞** |
| ❌ **不用** | 同步 SSRF（响应能从你发的请求里读到）——那用 `httpbin.org/redirect-to` 当跳板就够，不需要捕获口 |

**10 分钟是硬边界。** 盲 XSS 这类要等人的场景，抓到算赚，抓不到不能下「不存在」的结论。

## 7. 拿到命中之后

1. **不要只把「有回连」当结论**。回连证明「服务端确实发出了请求」，是一条独立事实，不等于「读到了数据」。写成 `fNNN` 事实，让后续 Reason 决定能不能升级。
2. **记录里带的信息本身有价值**：来源 IP 能证明是**内网哪台机器**发出来的（服务端而不是你），User-Agent 常常直接暴露后端技术栈，`Referer` 能证明是哪个页面触发的。
3. **别把捕获口当数据回传通道**。这里只存 2KB 预览，是用来证明「通了」的，不是用来搬文件或跑 C2 的——那用 `axiom c2`。

## 8. 纪律

- **只对授权目标发**。这个 URL 是公网可写的，谁拿到都能往里灌垃圾，所以「列表里出现一条记录」本身不构成任何证据，必须能和**你自己发出的 payload** 对上时间、对齐标签。
- **不要把它当成长期基础设施**。10 分钟自毁是设计不是缺陷：要长期回连通道，用 `axiom c2`。
- **别人可能也在用**。桶是全局单例，看到不认识的标签先别慌，看看是不是另一个任务在跑。
