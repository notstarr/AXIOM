Judge · 裁判管理

任务开启监管后，bootstrap / explore 的工具调用会先经过白名单、硬规则和裁判模型。

建议 3 秒；超时 fail-open，不阻断任务。

白名单

命中白名单的工具调用与 bash 命令直接放行，不进入裁判模型。

裁判提示词

用于非白名单、非硬规则工具调用的模型裁判。输出协议必须保持 ALLOW / BLOCK:<原因>。

保存后立即影响后续裁判模型判断，不影响白名单和硬规则。

硬规则 BLOCK

每行：原因 + Tab + 正则。命中后直接阻断，不进入裁判模型；行首加 # 可临时禁用该规则。

建议只放确定性强的规则；正则保存前会由后端校验。

DingTalk · 钉钉告警与指令交互

开启后，探针上报和评审漏洞将实时推送到钉钉群，并响应群内指令。

Stream 模式群指令交互（可选）

填写钉钉开放平台「企业内部应用」的 AppKey/AppSecret 后，即可在群里发 /help、/status 172、/pause 172 等指令由 AXIOM 响应（无需公网回调地址）。
