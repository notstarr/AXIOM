# AXIOM Explore 实时对话与人工插话

## 目标

Task 工作台新增“实时对话”视图：左侧列出全部未归档 Explore Intent，右侧展示当前 Intent 的工具调用、工具结果、行动摘要、Compaction/重试/收口事件和人工指导消息。

这里展示的是**脱敏后的行动摘要**，不是隐藏思维链。工具调用会明确显示工具名称；Shell/Bash 调用显示脱敏后的实际命令，其他工具显示脱敏后的关键参数。原始 Pi Session JSONL 仍是审计事实源，不被前端直接暴露。

对话区右下角提供“最新进展”按钮。点击后直接读取当前 Intent 最新一页活动并滚动到底部，不需要等待前端逐页追赶较长的历史 Session。

## 跨进程消息链路

人工消息写入 `intent_interventions`，绑定 `task_id + intent_id + lease_id`，并用 `client_message_id` 做幂等去重：

```text
前端 POST intervention
  → API 持久化 pending
  → Runner RPC Supervisor 每秒轮询并 claim
  → Pi stdin 发送 steer
  → response 成功/失败
  → API 更新 accepted/failed
```

消息只在当前 Explore Lease 内有效。执行阶段工具调用期间，Pi 会把 steer 排队到下一轮模型调用前；Lease 结束时 pending/sent 消息标为 `expired`，不会被下一次重试重放。

人工指导只影响当前 Explore 的上下文，不改变 Scope、工具权限、成功判据、Todo/Intent 规划关系或漏洞/Fact 协议。新增攻击方向必须由 Reason/Todo/Intent 正式规划。

## 读取与安全边界

- 对话接口复用 Task/Intent 现有资源：`GET /tasks/{task_id}/explore-conversation`。
- Session 中只提取工具名称、脱敏后的命令/关键参数、工具结果摘要、assistant 行动摘要和有限生命周期事件。
- Authorization、Cookie、JWT、API Key、Token、密码和类似凭证在服务端脱敏；文件写入正文等大参数不作为隐藏思维链展示。
- `x-text` 渲染摘要，避免把 Session 文本当 HTML 注入。
- Bootstrap、Reason 不接收人工 Explore intervention；Conclude 继续复用同一 Explore Session，但仍受当前 Lease 和阶段合同约束。
