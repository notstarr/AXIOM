# AXIOM 原生 AI 浏览器与 Lease 隔离

## 背景

旧 Explore 浏览器链路为：

```text
Pi Bash → cdp_ctl.py → 每个命令重新 connect_over_cdp → 共享 Chrome
```

它存在重复 Attach、元素编号漂移、无 Tab ID 时误选页面、共享 mitmproxy 流量被清空等系统性风险。

## 当前实现

Explore 启用 `browser-control` Skill 时，Pi 加载 `axiom-browser` Extension，直接获得 19 个 `browser_*` Tool。Runner 内的 Browser Broker 使用 Unix Socket 接收调用，并持有单个 Playwright CDP 连接：

```text
Explore RPC
→ browser_* Tool
→ Lease Token（Extension 内部注入，不出现在 Tool Schema/结果中）
→ Runner Browser Broker
→ Lease 私有 Page
→ 共享 Chrome-SecTest Profile
```

Bootstrap、Reason 和 Reviewer 不加载这些 Tool。共享 Profile 保留登录态，但页面所有权由 Lease 强制隔离。

## Page、Snapshot 与 Ref

- `page_id` 只在当前 Lease 内有效；除打开和列举外所有操作都必须明确提供。
- 点击、填写、按键、悬停、下拉选择、勾选和上传必须使用 Snapshot 返回的准确 Ref。
- Snapshot 支持 `interactive/viewport/subtree/full/changes`。
- Ref 包含 `role/accessible_name/text/attributes/allowed_actions`。
- Ref 在同一 Document Generation 中尽量稳定；导航、Broker重连或元素脱离文档后返回 `stale_ref`。
- 服务端验证 `allowed_actions`，不会根据相似文本或 URL 回退到其它元素、页面或 Lease。
- iframe 和开放 Shadow Root 可读取；关闭 Shadow Root 不可访问。

## 生命周期与审计

Browser Lease 覆盖 Explore Execute 和 Conclude。页面在整个 Intent Lease 结束时统一关闭，Pi 单个 RPC 进程结束不会提前清理页面。Lease 丢失、任务停止和 Runner关闭都会触发清理。

以下事件按 Page/Lease 写入 `process/browser/`：

- HTTP 请求与响应；
- WebSocket 帧；
- Console、Page Error 和 Dialog；
- 下载文件和索引。

读取使用增量游标，不存在影响其他 Worker 的全局 `clear`。敏感 Header 默认在 Tool Result 中脱敏，原始记录仍留在受控运行目录供授权测试使用。

## 兼容边界

- `cdp_ctl.py` 保留给运维和历史脚本，模型 Skill 不再提供其命令手册。
- Lease 环境下未提供明确 `--tab-id` 时，旧 CLI 直接失败。
- mitmproxy 保留为人工诊断能力，不再是 Worker 浏览器网络记录的默认来源。
- 首版不提供视觉问答、视觉定位、多浏览器内核、移动端模拟或网络 Mock。

## 验证

2026-08-04 已使用本机共享 Chrome-SecTest 和隔离的本地测试页面完成：

```text
open_page
→ snapshot
→ fill
→ click
→ read_page
→ read_console
→ read_network
→ close_page
```

链路复用单次 CDP Attach，并额外验证了：

- 两个并行 Lease 不能列举或读取对方页面；
- 操作后 `changes` 可返回变化摘要；
- 导航后旧 Ref 返回 `stale_ref`；
- Console/Network 持久化记录含明确 `page_id`；
- 客户端断开会取消正在执行的 Broker 操作；
- Runner 在成功、异常和 Lease 失效路径都会调用 Executor 清理。

最终回归为 `470 passed, 1 warning`；Ruff、compileall、Shell/JavaScript 语法、Pi 0.82.1 Extension 加载和 `git diff --check` 均通过。唯一 warning 为既有 Starlette/httpx 弃用提示。
