# bsk 升级到 0.3.2 与验收清单

日期：2026-10-09
相关仓库：`xrayAI/BrowserSkill`（axiom 的 submodule）、`xrayAI/axiom`

---

## 一、升级做了什么

把 axiom 的 bsk 私有补丁从 **0.3.0 fork** 移植到 **上游 0.3.2**，并**舍弃**上游已具备的能力。

### 移植范围（21 → 17 文件）

| 能力 | 处置 | 依据 |
|---|---|---|
| `credentials` 凭证提取（cookie 含 HttpOnly + web storage） | ✅ **保留** | 上游至今没有：0 个文件引用 `chrome.cookies`，且在调试证据里反过来对 cookie 做脱敏 |
| network 响应体捕获 | ❌ **舍弃** | 上游 `debug request <id> --part response` 已覆盖 |
| DevTools 式网络索引 + 单包详情 | ❌ **舍弃** | 上游网站调试（`bsk debug`）是严格超集 |

**关键判断依据**：上游 `bsk network` 与我们的 fork **注释、`since`/`limit`/`max_text_chars` 三个参数逐字相同** —— 说明 fork 原本就是在它之上做扩展，而 0.3.1 用网站调试把这块整体重做并超越了。

**不能省的一步**：舍弃 network 的前提是「上游 `debug` 能拿到等价信息」。实测已确认（见第五节），不是靠推断。

### 移植中发现并修复的真 bug

0.3.1 blueprint 分支的 `c7d57a3` **漏了 daemon 转发名单**。0.3.0 线的 `dcf5862` 当年加过这一行，移植时没带过来：

```rust
// crates/bsk-cli/src/daemon/ipc.rs
| Method::ToolNetwork
+ | Method::ToolCredentials      // dcf5862 加了，c7d57a3 漏了
| Method::ToolSnapshot
```

症状：`credentials` 落到 `other =>` 兜底分支，报 `method not implemented yet: ToolCredentials`。

**换句话说：blueprint 那份即便构建出来，凭证提取也是坏的。** 因为从未构建部署过，这个 bug 藏了半个多月。本次已修。

> 教训：编译通过 + 单元测试全绿 **不等于** 功能可用。这个 bug 只有端到端调用才能发现。

### 其它改动

| 改动 | 说明 |
|---|---|
| session idle 默认值 5 分钟 → 30 分钟 | 渗透 Intent 会整轮保持多个浏览器会话，上游默认值会在运行中途静默回收 session |
| skill 文档对齐 0.3.2 | 见第四节 |
| `axiom-extension/` 部署副本 | 改为构建产物 + gitignore（原为入库的预构建包） |

## 五、验收关键项：`debug` 确实能替代被舍弃的 network

这是整个「舍弃 network」决策的唯一实测依据：

```
request.response_body.state  = available
request.response_body.text   = "<!doctype html>…完整正文（719 字符）"
request.integrity.response_headers = complete
+ duration_ms / transfer_bytes / decoded_bytes / initiator / from_service_worker
```

**不仅等价，还多于 fork 原实现**（fork 没有 duration / initiator / 字节统计）。

同时确认了 `run.environment.extension_version = 0.3.2`。

## 六、axiom skill 对齐（本次一并修改）

axiom 内置 skill 里原有一段讲 `network --clear / --detail <seq> / --url / --all` —— **那正是被舍弃的 fork 参数**。0.3.2 的 `network` 只有 `--since/--limit/--max-text-chars`，该段会让 agent 调用不存在的参数。

`src/axiom/dispatcher/skills/browser-skill/SKILL.md`（149 行 → 167 行）：

1. 命令清单加入 `debug`
2. 重写 network 段：说明它**只返回索引**，需要请求头/正文时改用 `debug`
3. 新增 `debug` 完整工作流（`start → requests → request --part response → export → stop`）
4. 补齐 `debug` 其余能力：aggregate / duplicates / performance / rules / replay / console / pages / operations
5. frontmatter 标注「命令面与上游 bsk 0.3.2 对齐」
6. `tools/axiom-bsk` 注释更正（旧注释称"上游 0.3.1 起已移除 credentials"，事实是**上游从未提供**）

**验证**：全仓再搜 `network --detail` 等 fork 专有参数 → 0 残留。
