# AXIOM Task 级归档与产物隔离

## 背景

Task 通常已经包含 Fact、Intent、Todo、Artifact、漏洞、Goal Evaluation、ReviewRun 和 Audit Event。
直接物理删除会受到外键保护，也不符合保留执行历史的要求。此前前端仍提供删除入口，但缺少一个覆盖整项
Task 的可逆归档能力，因此删除含历史数据的 Task 会返回服务错误。

本次新增 **Task 级归档**。它与既有 Fact/Intent 链路级联归档是两套不同用途的能力：

| 能力 | Task 级归档 | Fact/Intent 链路归档 |
|---|---|---|
| 作用范围 | 整个 Task | 一个 Fact/Intent 根及其下游闭包 |
| 数据记录 | `tasks.archived` | `archive_batches/archive_batch_members` 与成员 `archived` |
| 主要目的 | 暂时隐藏整项任务并停止调度 | 清理重复或无价值的局部攻击链 |
| 恢复方式 | 恢复 Task 开关 | 按归档批次恢复并处理重叠覆盖 |
| 文件处理 | 不删除 | 不删除 |

## 数据与接口

迁移 `20260805_0035_task_archiving` 为 `tasks` 增加：

```text
archived boolean not null default false
index (archived, status)
```

接口：

```http
POST /api/v1/tasks/{task_id}/archive?actor=human.frontend
POST /api/v1/tasks/{task_id}/unarchive?actor=human.frontend
```

归档和恢复都使用 SQLite immediate transaction，并分别记录 `task.archived`、`task.unarchived` Audit
Event。操作不修改 Task 原状态、Goal Cycle、Intent/Todo/漏洞状态，也不删除数据库记录、Artifact 文件、
Session、Context Revision 或 Audit 历史。

## 归档约束

Task 级归档遵守以下边界：

1. 历史只读 Task 不能归档或恢复归档。
2. `running` Task 必须先暂停，不能在主执行链仍运行时归档。
3. Intent、ReasonRun 或 ReviewRun 中仍存在 `claimed/running/concluding` Lease 时拒绝归档。
4. 并发改变归档状态时返回冲突，不静默覆盖。
5. 已归档 Task 不能修改配置、Hint、Todo、漏洞或 Goal，不能上传 Artifact、继续 Goal、人工触发 Reason、
   暂停或恢复运行。

恢复只翻转 `archived=false`，保留归档前的 Task 状态，不自动 Resume，也不创建 ReasonRun。恢复后仍按
原状态和现有调度规则处理保留的 pending 工作。

## 调度与 Worker 隔离

Dispatcher Snapshot、活动 Lease 恢复、Intent/ReasonRun/ReviewRun 领取和 Reason Trigger 均排除归档
Task。Execution start 事务也会再次拒绝归档 Task，避免归档与领取之间的竞争窗口。

归档 Task 不能创建新的 Context Revision，`/context/expand` 也拒绝读取该 Task。已经生成的历史 Context
快照和运行文件仍保留在磁盘，但不会再披露给新 Worker。

## 人类页面与产物隔离

Task 列表继续显示 Task 的基础壳信息、状态和“已归档”徽章，方便人类找到并恢复；归档 Task 不再允许打开
正常概览或图谱。通过旧地址进入详情时只显示归档锁定页和“恢复任务”按钮。

归档期间以下内容从正常产品视图和 API 中隐藏：

- Hint、Fact、Intent、Todo 和 Goal 记录；
- Artifact 列表、文件夹、内容预览与下载；
- 漏洞列表与漏洞详情；
- 图谱、Context 和细粒度归档批次详情。

跨 Task 的文件中心、漏洞列表和项目活动统计也排除归档 Task。恢复后原有内容重新可见，不需要重建或复制。

物理删除仍保留兼容入口，但数据库外键拒绝删除有执行历史的 Task 时，服务会返回明确冲突：应使用
“归档任务”，而不是暴露底层 IntegrityError。

## 验证

- running Task 归档返回 409，并要求先暂停；
- stopped Task 归档后状态仍为 stopped，恢复后也不会自动运行；
- 归档后 Hint、Graph、Todo、Vulnerability、Artifact、Goal API 均拒绝披露；
- 恢复后历史图谱和产物可再次读取；
- Dispatcher、Reason、Context、Artifact、漏洞等服务均有归档守卫；
- 生产迁移已升级到 `20260805_0035`，SQLite integrity 为 `ok`，foreign key violation 为 0。
